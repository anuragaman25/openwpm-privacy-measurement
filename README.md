# OpenWPM – Web Privacy Measurement Setup & Analysis

This repository documents the complete setup, configuration, and validation of **OpenWPM**, an open-source framework for automated web privacy measurement. The project demonstrates how to deploy OpenWPM on Kali Linux, configure Firefox ESR, build the OpenWPM browser extension, and run automated crawls for privacy analysis.

> [!IMPORTANT]
> This repository contains documentation and example scripts only.  
> The OpenWPM framework is an open-source project maintained by its original authors.  
> Refer to the official OpenWPM repository for the full source code: https://github.com/openwpm/OpenWPM

## What This Project Covers

- End-to-end installation of OpenWPM on Linux (Kali tested)
- Firefox ESR configuration for Selenium-based automation
- Building and integrating the OpenWPM browser extension
- Running automated privacy measurement crawls
- Troubleshooting common setup issues
- Professional deployment report for reproducibility

## Tech Stack

- OpenWPM (Web Privacy Measurement Framework)
- Python (Conda Environment)
- Firefox ESR
- Selenium WebDriver
- Node.js & npm (for extension build)
- Kali Linux (Debian-based)
